# Data Science do Zero 🚀

Este repositório contém meus estudos, anotações e códigos baseados no livro **"Data Science do Zero"** (Data Science from Scratch) de Joel Grus.

## 📖 Sobre o Projeto
O objetivo deste repositório é documentar minha jornada de aprendizado sobre os fundamentos de Ciência de Dados, implementando algoritmos e conceitos "do zero" em Python, sem o uso inicial de bibliotecas complexas, conforme a proposta do livro.

## 📁 Estrutura do Repositório

- `/capitulo_1_introdução/`: Conceitos introdutórios, motivação e primeiros exemplos práticos.
- `/capitulo_2_python/`: Um curso intensivo de Python, relembrando os fundamentos da linguagem que serão utilizados ao longo do livro.

*(Mais capítulos serão adicionados conforme o progresso da leitura)*

## 🛠️ Tecnologias Utilizadas
- **Python 3.12.9**
- (Outras bibliotecas adicionadas futuramente)

## 🚀 Como Executar
1. Clone o repositório:
```bash
git clone https://github.com/AndreLuis0106/data_science_do_zero.git
```
2. Crie e ative um ambiente virtual (recomendado):
```bash
python -m venv venv
# No Windows
venv\Scripts\activate
# No Linux/Mac
source venv/bin/activate
```
3. Navegue até o capítulo desejado e execute os scripts Python:
```bash
cd capitulo_1_introdução
python "Capitulo 1 - Introdução.py"
```
